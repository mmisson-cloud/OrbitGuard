Explainable decision support · Not an autonomous AI agent

Recommendation logic is a deterministic safety rule based on the generated model results. No OpenAI API is connected in this standalone page; do not label it as a trained AI forecast.

⚠ Educational research model. Open-radiator time during simulated dust is a proxy for possible exposure, not a measure of deposited dust or damage. The 40°C limit and other parameters are illustrative. This demo has no real rover connection, flight qualification, dust deposition model, or NASA approval.
